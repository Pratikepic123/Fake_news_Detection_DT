# Electric Vehicle Market Analysis – Washington State

## Project Overview

This project analyzes electric vehicle registration data from Washington
State to identify EV adoption trends, popular manufacturers and models,
vehicle types, geographic distribution, and electric range patterns.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains electric vehicle registration information including:

- Vehicle Make
- Vehicle Model
- Model Year
- Electric Vehicle Type
- Electric Range
- CAFV Eligibility
- County
- City
- State
- Electric Utility

## Analysis Performed

- Data understanding
- Data cleaning
- Missing-value analysis
- Duplicate analysis
- Exploratory Data Analysis
- Manufacturer analysis
- EV model analysis
- BEV vs PHEV analysis
- Geographic analysis
- Electric range analysis
- Model-year analysis

## Key Questions

1. How many EVs are registered in total?
2. What is the percentage of BEVs vs PHEVs?
3. Which 5 manufacturers have the highest number of registered EVs?
4. What are the top 10 most registered EV models?
5. Which model year has the highest number of registered EVs?
6. Which counties have the highest number of registered EVs?
7. Which cities have the highest number of registered EVs?
8. Which manufacturers are strongest in BEVs and PHEVs?
9. Which EV models have the highest average electric range?
10. Does electric range appear to improve for newer model years?

## Key Insights

- The dataset contains 289,564 registered electric vehicles.
- BEVs represent the majority of registered EVs.
- Tesla, Chevrolet, Nissan, Ford, and Kia are among the leading manufacturers.
- Tesla Model Y is the most registered EV model.
- EV registrations are concentrated in major geographic areas.
- Average electric range does not show a consistently increasing trend across newer model years.

## Conclusion

This analysis provides insights into EV adoption, manufacturer and model
popularity, geographic distribution, and electric-range characteristics
in Washington State.
